# [Checking and update costs in random walk search with several marked states](article.pdf)

Knowledge Sense
12 October 2026

We establish update–check tradeoffs for random walk search with several marked states in local access models. A translated family on lazy cycles shows that the cost split available for a single marked state does not extend to several marked states.
