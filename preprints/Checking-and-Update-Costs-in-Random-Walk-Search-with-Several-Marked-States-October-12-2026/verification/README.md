# Finite mathematical diagnostics

Author: Knowledge Sense

Run `python check.py` with Python 3 and its standard library. The program writes `results.json` alongside the script. It checks the exact stationary hitting-time formula through independent rational Poisson systems, the marked mass and gap counts, cyclic interval intersection counts, restoration connectedness, selected adaptive all-negative coupling policies, lazy range estimates, exit times, and the spaced-net upper bound.

The adaptive checks enumerate selected policies and finite paths, not all algorithms. Finite calculations supplement the analytic proof and do not establish asymptotic claims or literature novelty.
