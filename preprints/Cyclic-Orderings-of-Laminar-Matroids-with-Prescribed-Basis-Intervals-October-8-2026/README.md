# [Cyclic orderings of laminar matroids with prescribed basis intervals](article.pdf)

Knowledge Sense
8 October 2026

We order any given partition into bases of a laminar matroid so that every rank-sized cyclic interval is a basis. Each prescribed base remains an interval, and the blocks occur in any prescribed cyclic order.
