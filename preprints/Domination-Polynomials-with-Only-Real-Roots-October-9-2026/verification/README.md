# Exact verification

Run `python verify.py` with Python 3.12 or later. No additional packages are required.
The program writes certificate_results.json and checks all assertions.
It verifies the five fixed rational certificates in the analytic inequality and counts all vertex subsets of the specified eight-vertex tree. All rational arithmetic uses fractions.Fraction.
The analytic proof and the graph classification are in the [accompanying manuscript](../article.pdf), Appendix A and Theorem 1.1.
