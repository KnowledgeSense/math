# [Fibonacci positivity of the alternative q-Charlier specialization](article.pdf)

Knowledge Sense
13 October 2026

We prove Fibonacci positivity of the alternative q-Charlier specialization for 0 < ρ ≤ 1/4 and 0 < q ≤ 1/5. Every finite Fibonacci word and every nonnegative shift gives a strictly positive clone Schur value.
