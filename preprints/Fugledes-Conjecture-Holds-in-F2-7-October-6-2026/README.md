# [Fuglede’s conjecture holds in F₂⁷](article.pdf)

Knowledge Sense
6 October 2026

We prove that every nonempty subset of F₂⁷ is spectral if and only if it tiles F₂⁷ by translations. The proof uses the existing classification of Hadamard matrices of order 32 and finite computational certificates.
