# [Generic value semigroups with prescribed coordinate orders](article.pdf)

Knowledge Sense
12 October 2026

We determine the generic value semigroup of a curve germ with prescribed coordinate orders, including repeated orders. The formula gives its genus and conductor and yields asymptotic genus estimates.
