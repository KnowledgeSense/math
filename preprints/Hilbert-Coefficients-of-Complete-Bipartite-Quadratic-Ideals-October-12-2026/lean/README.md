# Hilbert coefficients of complete bipartite quadratic ideals

Lean formalization accompanying the [manuscript](../article.pdf).

`HilbertBipartite.release_main_theorem` proves all four parts for every field
and every `1 ≤ p ≤ q`:

- The exact composition length of the quotient by every positive ideal power
- The Hilbert expansion for every positive power, with the explicit coefficient formula
- The positive initial coefficients, vanishing last coefficient, and strict higher signs
- Nonnegativity exactly when `p` is odd, and `q−1` consecutive negative coefficients when `p` is even

The ideal is an actual `MvPolynomial` ideal generated by variable squares and
all cross-block products. Standard monomials give a quotient basis. The proofs
identify vector-space dimension with literal polynomial-ring module length.
The coefficient family is also proved unique in the eventual Hilbert–Samuel
polynomial convention, directly from those module lengths.

## Main declarations

All names below are in the `HilbertBipartite` namespace.

- `release_main_theorem`: the complete release theorem
- `actual_length_explicit_expansion`: the all-powers expansion with explicit coefficients
- `compositionLength_formula`: the exact finite length formula
- `hilbertCoefficient_unique`: uniqueness in the paper's Hilbert convention
- `hilbertCoefficient_eq_formula`: the coefficient-extraction identity

`coefficientFormula` expresses extraction through a finite convolution. Its
zero branch at the last index implements the paper's convention that a
negative extraction index contributes zero. `Module.length` takes values in
`ℕ∞`; the exact length theorem proves finiteness before the rational expansion
uses `toNat`.

## Build

From the repository root, run:

```sh
lake exe cache get
lake --wfail build HilbertBipartite
lake script run audit HilbertBipartite
lake env leanchecker --fresh HilbertBipartite
```

The shared toolchain and dependency revisions are pinned at the repository root.
