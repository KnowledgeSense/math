# [Log-concavity of pure O-sequences of given codimension and type](article.pdf)

Knowledge Sense
8 October 2026

We classify the codimension and type pairs for which every pure O-sequence is log-concave: r ≤ 2, t = 1, or (r,t) = (3,2). Explicit infinite counterexample families establish every remaining pair.
