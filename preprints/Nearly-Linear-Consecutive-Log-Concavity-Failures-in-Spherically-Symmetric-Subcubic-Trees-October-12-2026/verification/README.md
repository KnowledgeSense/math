# Spherical tree coefficient verification

Author: Knowledge Sense.

Run `python verify.py` with Python 3.12 or later. Only the standard library is required.
The JSON records exact coefficient recurrences against independent graph deletion, independence numbers, maximum degree, root support, exponential tilting and discrete determinant identities for 12 finite trees. It also checks 30 reverse-path coefficient bounds and rational finite-height martingale variances. The 100-digit Decimal calculation illustrates the fixed-point parameter at k=16384. It does not certify the asymptotic threshold or replace the proof.
