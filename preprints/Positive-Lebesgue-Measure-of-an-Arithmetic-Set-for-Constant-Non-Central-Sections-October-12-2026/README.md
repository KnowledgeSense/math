# [Positive Lebesgue measure of an arithmetic set for constant non-central sections](article.pdf)

Knowledge Sense
12 October 2026

We prove that the arithmetic set in Haddad and Ryabogin’s rigidity theorem for constant non-central sections has positive Lebesgue measure. Every neighborhood of their explicit example contains a positive-measure subset of this set.
