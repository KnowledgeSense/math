# [Schatten norm compression for 2 × N block matrices with diagonal blocks](article.pdf)

Knowledge Sense
8 October 2026

We prove Audenaert’s norm compression conjecture for 2 × N block matrices with diagonal blocks, for every Schatten exponent from 1 to infinity. The proof establishes the required convexity for exponents from 1 to 2 and obtains the remaining range by duality.
