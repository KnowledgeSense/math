# [Sharp size bounds for 3-connected positroids without a long line minor](article.pdf)

Knowledge Sense
8 October 2026

We prove the sharp parity-dependent size bounds conjectured by Boretsky and Walsh for 3-connected positroids with no U₂,ℓ₊₂ minor. For ℓ ≥ 4, we also classify every positroid attaining the bound.
