# Exact calculations for canonical doubles

Requires Python 3 and SymPy 1.14.0. From this directory, run:

    python -m pip install sympy==1.14.0
    python exact-calculations.py > exact-calculations.json

The calculations verify the gaps and genus of the base semigroup, the canonical ideal and duplication data, and the explicit Stöhr–Torres semigroups. These finite arithmetic checks supplement the deformation arguments in the manuscript.
