# Exact-arithmetic checks for inverse Z-polynomials of paving matroids

Author: Knowledge Sense

Use Python 3.8 or later. The code uses the standard library only.
Extract the three files into one directory, then run:

    python check_algebra.py

Run Python without -O or -OO. A failed assertion stops the program.
A successful run prints the results and writes algebra_check_results.json
beside the script. The supplied result file is generated by this command.

The script checks:

- the uniform coefficient normalization in Lemma 3.1;
- the equivalence of the two paving correction formulas after Theorem 2.6;
- the even-rank central increment in Lemma 3.2;
- the component ratio bounds in Lemma 4.1;
- single-hyperplane examples and the coefficient bounds of Section 6;
- the scalar inequality of Lemma 6.2.

The numerator expansion in Lemma 6.2 is checked as a polynomial identity
over the integers, with variables x, s, b. All numerical checks use integers
or exact rational numbers. No floating-point arithmetic is used.

Finite ranges: 1 <= k <= 24, k <= n <= k+40, k <= h <= n-1.
Scalar ranges: 1 <= b <= 14, 1 <= s <= 19, s <= a <= s+24.
The result contains 169,338 counted checks and the polynomial identity.
Finite checks supplement the analytic proof of the theorem.

The formulas used here are cited in the accompanying paper, with theorem
numbers referring to arXiv:2507.01332v1 and arXiv:2601.17314v1.
