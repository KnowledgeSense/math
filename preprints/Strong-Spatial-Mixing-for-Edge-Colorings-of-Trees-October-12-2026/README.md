# [Strong spatial mixing for edge colorings of trees](article.pdf)

Knowledge Sense
12 October 2026

For every ε > 0 and sufficiently large maximum degree Δ, we prove strong spatial mixing for proper tree edge colorings when q ≥ ((3 + √5)/2 + ε)Δ. The exponential decay is uniform over finite trees and feasible boundary pinnings.
