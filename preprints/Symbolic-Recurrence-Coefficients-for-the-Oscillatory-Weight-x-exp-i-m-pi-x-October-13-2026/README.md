# [Symbolic recurrence coefficients for the oscillatory weight x exp(i m π x)](article.pdf)

Knowledge Sense
13 October 2026

For every nonzero integer frequency, we prove four conjectured formulas for the recurrence coefficients of monic orthogonal polynomials with weight x exp(i m π x). One common family of rational-coefficient polynomials supplies all four formulas.
