# [The exact activity threshold for spectral independence of the hard-core model on trees](article.pdf)

Knowledge Sense
12 October 2026

For the hard-core model on finite forests, we determine the exact activity threshold for uniform spectral independence and a Glauber dynamics spectral gap of order 1/n. The threshold is approximately 15.6737 and holds without a degree bound.
