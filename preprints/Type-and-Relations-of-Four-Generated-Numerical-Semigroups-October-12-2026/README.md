# [Type and relations of four-generated numerical semigroups](article.pdf)

Knowledge Sense
12 October 2026

For every numerical semigroup of embedding dimension four, we prove t + 1 ≤ η ≤ 2t + 3, where t is the type and η is the number of relations in a minimal presentation. Both bounds are attained.
